# Tech Challenge Fase 04

## Visão geral

A fase 04 do projeto foi desenvolvida conforme a exigência do enunciado: a aplicação foi adaptada para React Native, mantendo a base funcional já validada nas entregas anteriores.

A solução atual preserva a lógica de autenticação, o fluxo de posts e a experiência de leitura/curtida/comentário, mas reorganiza a interface para um ambiente mobile mais direto e funcional.

---

## Objetivo da etapa

A fase 04 tem como objetivo evoluir a solução anterior para um ambiente mobile, reaproveitando a base funcional já confirmada e ajustando os fluxos para usabilidade em telas menores.

---

## Base reutilizada

A implantação atual preserva os pilares já validados do projeto:

- autenticação e perfis de usuário;
- regras de negócio e autorização;
- fluxo de posts, comentários e curtidas;
- organização de documentação e entrega por etapa.

---

## Tecnologia da fase

A implementação desta etapa está em React Native com Expo, seguindo o requisito explícito do trabalho.

---

## Estrutura da entrega

A fase 04 está organizada em:

- [mobile](mobile): aplicação principal em React Native;
- [PLANEJAMENTO.md](PLANEJAMENTO.md): planejamento da etapa;
- [DOCUMENTACAO_ENTREGA.md](DOCUMENTACAO_ENTREGA.md): documentação de entrega.

---

## Funcionalidades atuais da app mobile

A implementação mobile inclui:

- login de usuário;
- listagem e busca de posts;
- visualização do detalhe do post;
- curtidas e comentários;
- administração de posts por professores;
- cadastro, edição e exclusão de usuários por professores;
- persistência local no dispositivo.

---

## Como executar

A partir da pasta do app mobile:

```bash
cd "TRABALHO 4/mobile"
npm install
npx expo start
```
